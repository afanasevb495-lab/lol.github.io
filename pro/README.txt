PRO Класс — сайт. Работает на любом хостинге с PHP 7.4+ (почти любой обычный хостинг).

1. Загрузите ВСЁ содержимое папки по FTP/через файловый менеджер в корень сайта (public_html или www).
2. Дайте хостингу права записи на: index.html, папки uploads и backup (обычно 644/755 уже достаточно, если файлы ваши).
3. Админка: нажмите на название «PRO Класс» в шапке 3 раза подряд (или откройте адрес сайта с #admin на конце).
   Логин: admin    Временный пароль: vQ84pAM33u
   Сразу смените пароль кнопкой «Сменить пароль» в панели.
4. В панели: правка текстов и цен, замена фото кликом, + Курс, + Отзыв, ссылка VK, «Сохранить на сайт».
   Перед каждым сохранением старая версия копируется в папку backup (последние 15).
Без PHP сайт открывается как обычная статическая страница, но редактировать его нельзя.
